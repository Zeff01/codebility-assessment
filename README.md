# Frontend Assessment – Product Listing Page

## Overview

This repository contains my implementation of the **Frontend Assessment (3–5 Years)** for Codebility.
The task was to create a product listing page with data fetching, a detail view, filtering/search functionality, and responsive design.

---

## Features

- **Product Listing**

  - Fetches product data from [Fake Store API](https://fakestoreapi.com/).
  - Displays products in a responsive grid.
  - Shows product image, title, price, and category.

- **Product Detail View**

  - Opens a modal with more product details when a product is clicked.
  - Includes product description, price, image, and category badge.
  - Smooth slide-up and slide-down animation for modal using Framer Motion.

- **Filtering & Search**

  - Filter products by category.
  - Search products by title in real-time.

- **Responsive Design**

  - Works on mobile, tablet, and desktop screen sizes.
  - Uses TailwindCSS for styling and responsive layouts.

- **Loading & Error Handling**
  - Shows loading state while fetching data.
  - Displays an error message if the API request fails.
