### Implemented Instagram-style login and feed screens based on the design mockup.
____________________
**What was implemented:**

- Login screen with email/password inputs, Facebook login, and remember me checkbox
- Feed screen with top navigation, stories section, posts with engagement, and bottom navigation
- Responsive layout matching the design specifications

**Folder structure:**

- app/(auth)/ - Authentication screens (login, signup)
- app/(tabs)/ - Tab-based navigation screens
- components/auth/ - Reusable auth components (Input, Button, Checkbox)
- components/feed/ - Feed components (TopNavigation, StoriesSection, Post, BottomNavigation, etc.)
- constants/ - Theme, colors, and strings constants
- hooks/ - Custom hooks (useButtonPress)

**Custom icons:**
Custom image assets were used for Instagram logo, Facebook logo, Instagram TV icon, verified badge, and profile icon because @expo/vector-icons doesn't include exact matches. This approach was chosen due to a 2-hour time constraint to match the design mockup.
