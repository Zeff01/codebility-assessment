# Frontend Technical Assessment for Codebility

## Introduction

This project represents my submission for the frontend developer position of 1-2 years at Codebility. The implementation showcases my approach to frontend development while adhering to the requirements of the assessment.

## Development Approach

While this project aligns with the assessment criteria, I've incorporated several personal development practices that reflect my experience and philosophy as a frontend developer:

- **Modular Architecture**: Components are structured independently with clear separation of concerns, making the codebase more maintainable and scalable.

- **Consistent Horizontal Padding**: I've applied uniform horizontal padding throughout the interface.

- **Extensive Use of Flexbox**: With my background in UI/UX design and Figma, I've heavily utilized Flexbox for layouts due to its conceptual similarity to Figma's "Auto Layout" feature. This approach allows for more responsive and adaptable interfaces.

## Technical Implementation

The project is built using Next.js with TypeScript and styled with Tailwind CSS, demonstrating modern frontend development practices while maintaining clean, readable code.

Throughout the development process, I focused on creating components that are both functional and visually appealing, with careful attention to responsive design principles.

I improved the responsiveness of the original website as well.
