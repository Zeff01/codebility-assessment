This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Folders

# > /data

Stores the array of blog posts

# > /components

Stores reusable components used throughout the site

# > /types

Stores types.ts, a collection of custom types used for type-safe rendering of blog posts.
